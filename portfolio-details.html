TEAM PROJECT · REBRANDING

동래읍성역사문화축제 리브랜딩

전통문화와 현대적인 디자인을 연결한 축제 아이덴티티 리브랜딩 프로젝트입니다. 기존 축제의 시각적 한계를 개선하고 로고, 캐릭터, 홍보 콘텐츠, 반응형 웹페이지를 새롭게 기획하고 디자인했습니다.

Project Information

  • Project : 동래읍성역사문화축제 리브랜딩
  • Category : Team Project / Branding / UI·UX
  • Team : 읍성이
  • Period : 프로젝트 진행 기간 기입
  • Role : 캐릭터 디자인 및 웹 UI/UX 디자인
  • Tools : Photoshop / Illustrator / Figma / HTML / CSS
01 · PLANNING

기획 및 정보구조도

축제의 콘텐츠와 사용자 동선을 분석하고 방문객이 필요한 정보를 쉽게 찾을 수 있도록 정보구조도와 프로젝트 기획을 진행했습니다.

02 · BRANDING

로고 및 캐릭터 디자인

축제의 역사성과 정체성을 바탕으로 현대적인 시각 언어를 적용한 로고와 캐릭터를 디자인했습니다.

03 · WEB DESIGN

반응형 웹페이지 디자인

PC, 태블릿, 모바일 환경에 최적화된 반응형 웹페이지를 구성하고 축제의 브랜드 아이덴티티를 일관되게 적용했습니다.

04 · PROMOTIONAL VIDEO

축제 홍보 영상

축제의 브랜드 콘셉트와 주요 콘텐츠를 영상으로 표현하여 온라인 홍보와 방문객의 관심을 유도합니다.
